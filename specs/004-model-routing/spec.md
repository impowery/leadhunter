# 004 — Маршрутизация моделей по задаче (cheap-first)

## Проблема
Модели захардкожены по одной на тир. Бенчмарк на реальном скоринге (3 эталонные вакансии) показал:
бесплатные deepseek-v4.1-flash:free / deepseek-v4-flash:free годны для скоринга; платные нужны только как страховка;
deepseek-v4.1-flash-1017 даёт то же качество, что deepseek-v4.1-flash, вдвое дешевле.

## Цель
- Списки моделей по тирам (bulk / quality / escalate), настраиваемые через окружение.
- Порядок в цепочке: бесплатные → дешёвые платные → OpenRouter → groq (хвост).
- Совместимость: старые LLM_QUALITY_MODEL / LLM_ESCALATE_MODEL ставятся первыми в соответствующий список.

## Вне scope
Логика скоринга, промпты, парсеры, доставка.
