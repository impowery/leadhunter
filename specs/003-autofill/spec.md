# 003 Autofill applications

## Зачем
Заполнение форм отнимает время и содержит одни и те же поля.

## Что меняется
Локальный скрипт на Playwright открывает вакансию в Chrome, заполняет стандартные поля,
подставляет письмо, сохранённое ботом для этого URL, прикрепляет CV и делает скриншот.
Кнопку Submit не нажимает.

## Требования
- URL берётся из буфера обмена или аргумента.
- Письмо берётся из локального файла last_letter.txt или из БД бота по URL через SSH.
- CV берётся из resume/Andrey_Mashkin_CV_EN.pdf.
- Заполняются имя, email, телефон, локация, ссылки, зарплата, notice, английский, cover letter.
- Скрипт не отправляет форму и оставляет браузер открытым для проверки.

## Вне рамок
Автосабмит, обход капчи, массовые отклики.

## Критерии приёмки
- На тестовой форме заполняются имя, email и cover letter.
- Письмо подтягивается из БД бота по URL.
- Скриншот сохраняется в apply/last_fill.png.
