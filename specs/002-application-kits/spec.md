# 002 Application kits

## Зачем
Отклик занимает 15-20 минут: письмо, ответы на типовые вопросы, поиск ссылок.

## Что меняется
Для сильных лидов бот присылает готовый пакет: письмо под вакансию и блок стандартных ответов,
плюс файл CV и кнопки результата.

## Требования
- Пакет уходит только владельцу, гостям не дублируется.
- Пакет собирается для лидов с decision recommend или fit >= 60, не более 3 за скан.
- Один и тот же лид не получает пакет дважды.
- Письмо на английском, 110-160 слов, без выдуманного опыта, без длинных тире.
- Ответы фиксированные и честные: английский fluent, UTC+7, старт сразу, оплата по ценности, ссылки.
- CV отправляется одним документом после пакетов.

## Вне рамок
Автозаполнение форм и авто-сабмит.

## Критерии приёмки
- Пакет приходит в Telegram с письмом, ответами и ссылкой.
- Повторный запуск не дублирует пакет для того же URL.
- Гостевые боты пакет не получают.
